FIX MY DATA 소개 및 사용 방법

이 서비스는 엑셀에서 저장하거나 다른 프로그램으로 내보낸 CSV/TSV 파일의 구조적 오류를 브라우저에서 점검하는 무료 도구입니다.

사용 방법

  1. 메인 화면에서 CSV·TSV·TXT 파일을 선택합니다. 5MB 이하 파일을 지원합니다.
  2. 인코딩과 구분자를 자동 추정하거나 직접 선택합니다.
  3. 열 개수 불일치, 닫히지 않은 따옴표, 인코딩 손상 징후를 확인합니다.
  4. 원본 데이터와 미리보기를 비교하고 안전하다고 판단될 때 CSV 파일을 내려받습니다.

특히 유용한 경우

엑셀에 불러온 CSV에서 열이 밀리는 경우, 여러 행 중 일부만 열 수가 다른 경우, 한글이 깨져 보이는 경우, 탭으로 구분된 TSV 파일을 쉼표로 잘못 읽은 경우 등에 활용할 수 있습니다.

데이터 손상 가능성

인코딩 자동 감지는 추정이며 잘못된 추정을 할 수 있습니다. 일부 형식이 잘못된 입력은 자동으로 완전 복구할 수 없습니다. 문제가 발견된 파일을 원본과 비교하지 않고 업무 데이터에 바로 적용하지 마세요. 원본 백업을 유지하는 것이 좋습니다.

시트 수식 관련 주의

CSV를 스프레드시트에서 열면 = 등으로 시작하는 값이 수식으로 취급될 수 있습니다. 내보내기의 방어 옵션은 위험을 완전히 제거한다고 보장할 수 없으므로 신뢰할 수 없는 데이터는 검증 후 여세요.
